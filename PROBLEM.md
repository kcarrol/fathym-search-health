# The problem

fathym.com changes every site batch, and between batches nobody knows whether it is still healthy for
search engines and AI crawlers: soft-200s on unknown URLs, missing canonicals, broken links, sitemap
drift. We also don't know which searches we should be writing for: keyword pulls from DataForSEO are
one-off and saved raw.

**Who has it:** Kilian, and anyone writing for the site.

**What solved looks like:** any of us, or any AI we use, can ask "is the site healthy, and what should
we write next?" and get the same current answer, along with what changed since last time.
